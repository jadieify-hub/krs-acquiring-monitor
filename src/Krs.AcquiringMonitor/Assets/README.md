# Иконка приложения

`app-icon.png` — исходный рисунок, созданный imagegen для KRS Эквайринг Монитора: банковская карта, бирюзовый пульс и отметка проверки на тёмно-синем фоне. Чужие логотипы и банковские данные не использованы.

`app.ico` содержит размеры 16, 24, 32, 48, 64, 128 и 256 пикселей. Для повторной упаковки из корня репозитория: `powershell -File build/build-icon.ps1`. Масштабирование и упаковка выполняются стандартным System.Drawing, без дополнительных пакетов.

ICO встроен в EXE и установщик. Трей и формы берут значок из того же EXE; отдельный файл рядом с установленной программой не нужен.
