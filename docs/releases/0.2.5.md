# KRS Эквайринг Монитор 0.2.5

Оверлей сумм банковской смены по организациям для Frontol 6 и Сбербанк UPOS. Это первый публичный выпуск после 0.2.2: в него вошли изменения локальных сборок 0.2.3 и 0.2.4.

## Что изменилось

- Убрана отдельная стрелка: двойной щелчок левой кнопкой по любой сумме запускает сверку всех организаций. «Обновить» в трее тоже обновляет суммы, не программу.
- Состояние запроса видно по цвету сумм и подсказке; ошибка не меняет сами числа.
- Ширину можно менять за правый край без изменения шрифта. Размер шрифта настраивается отдельно; открытые настройки показывают живой оверлей, «Отмена» возвращает прежний вид и положение.
- Убрано повторное дорогое чтение имени активного процесса. Проверка окна Frontol выполняется раз в секунду.
- Исправлено ошибочное распознавание статистики UPOS 7000 как закрытия смены 6000.
- Установленная версия проверяет обновления при запуске и каждые 6 часов. Установка ждёт спокойного момента, сохраняет состояние и ожидает завершения старого монитора. При ручной установке обновлена обработка зависшего процесса.

## Как установить или обновить

Скачайте `KRS-AcquiringMonitor-0.2.5-setup.exe` ниже и запустите в спокойное время поверх установленной версии. Сохранённые настройки и суммы остаются в профиле пользователя. Для 0.2.2 и старее рекомендуется этот ручной переход.

На установленной 0.2.3/0.2.4 можно дождаться автоматической проверки либо выбрать «Выход» в трее и снова запустить монитор. Проверка начнётся примерно через 3 секунды, установка дождётся 30 секунд без банковских операций и открытых окон настройки/справки. Перезагружать компьютер не нужно.

Для portable используйте `KRS-AcquiringMonitor-0.2.5-win-x86.zip`: закройте старую копию через трей и замените её файлы. Portable не обновляется автоматически.

`update.json` предназначен для автообновления; в нём опубликован SHA-256 установщика. Сборки x86 для Windows 10/11 и .NET Framework 4.8. Банковские DLL и пользовательские журналы в комплект не входят.

## Важно

- **Ошибка `report-format` на полевой конфигурации UPOS пока не исправлена.** Нераспознанный отчёт не применяется; прежние суммы по журналу сохраняются. Автоматический расчёт по журналу не равнозначен подтверждённой сверке с терминалом.
- Программа не выполняет оплату, возврат, закрытие банковской смены и не использует ККТ. Не заменяет штатный банковский отчёт.
- Сборки пока не подписаны Authenticode. Загружайте их только из этого репозитория.

Проверки перед выпуском: 72 автоматических теста и отдельные изолированные сценарии завершения старого процесса и передачи управления установщику. Живой банковский запрос в ходе выпуска не выполнялся.
