# KRS Эквайринг Монитор 0.2.17

Версию программы теперь можно сразу увидеть на кассе:

- первая строка меню значка рядом с часами;
- подсказка при наведении на значок;
- заголовок окна настроек.

Везде показана версия запущенной сборки. Справка и диагностика сохраняют прежнее отображение версии.

Исправление названий UPOS из 0.2.16 включено. Если после обновления той версии привязка уже восстановлена, повторный сброс не требуется. Настройки оформления и суммы сохраняются. Порядок запросов к банковскому ПО не изменён.

Проверено: 101 тест и x86 Release. Проверка окна банковского обновлятора на кассе не выполнялась.

## Файлы

- `KRS-AcquiringMonitor-0.2.17-setup.exe` — рекомендуемый установщик.
- `KRS-AcquiringMonitor-0.2.17-win-x86.zip` — portable-сборка.
- `update.json` — манифест автообновления с SHA-256 установщика.

Установленные копии могут проверить новую версию через трей → «Проверить обновление программы…»; установка ждёт безопасной паузы. Portable-копия обновляется вручную после выхода через трей.
