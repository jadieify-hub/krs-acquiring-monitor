# KRS Эквайринг Монитор 0.2.11

Настраиваемый оверлей сумм эквайринга по организациям для Frontol 6 и Сбербанк UPOS.

## Что изменилось

- Ширина по умолчанию — 370 пикселей. Ранее сохранённая ширина не меняется.
- «Сброс данных монитора…» очищает запомненные организации, ручные подписи и кэш сумм, затем перечитывает оставшиеся журналы. Оформление, путь UPOS и автозапуск сохраняются; банковские файлы не удаляются. Если чужие записи остались в журнале, они появятся снова.
- «Обновить суммы» и «Проверить обновление программы…» разделены в меню трея. Новую версию можно проверить без перезапуска; ошибки проверки отличаются от отсутствия обновления. Автоустановка ждёт доступного актуального журнала и безопасной паузы.
- Добавлена локальная «Диагностика…» с копированием технической сводки о журнале, Frontol и обновлении. Названия организаций, суммы и реквизиты не включаются; автоматической отправки нет.
- Своя иконка встроена в EXE, трей, окна, ярлык меню «Пуск» и установщик.
- Исправлен выход при уничтожении скрытого окна Windows: процесс больше не остаётся без окон в ожидании принудительного завершения установщиком. Пересоздание окна при настройке не завершает программу.
- Выход не ждёт блокировку читателя журнала; сохраняется последняя безопасная контрольная точка. Чтение журнала и проверки перед обновлением вынесены из потока интерфейса.
- Ссылка добровольной поддержки и локальный QR-код синхронизированы с действующими настройками проекта.

## Проверка и ограничения

88 тестов проходят. Повторная локальная установка поверх работающей 0.2.11 со скрытым оверлеем прошла за 1,34 секунды с отключённым принудительным закрытием. Отдельный тест проверяет штатный выход, замену EXE и сохранность посторонней копии. Это не заменяет приёмку на кассах.

Перед первым переходом со старой версии дождитесь паузы без банковских операций и завершите монитор через трей. Новый код не исправляет поведение уже запущенной старой версии.

Одна ручная установка встретила системную блокировку EXE: Windows указала `System` среди держателей файлов (`DeleteFile`, код 5). После исчезновения блокировки и штатного выхода монитора установка прошла. Причина не подтверждена, этот случай не объявляется исправленным. Не выбирайте «Пропустить этот файл»: отмените установку, выйдите из монитора через трей и повторите её. Защиту Windows отключать не нужно.

Контрольная лента UPOS с ненулевыми отменами пока не применяется. Поддержаны Department 1 и 2, максимум две организации. Сборка не подписана Authenticode; проверяйте источник и SHA-256 в `update.json`.

## Скачать

- `KRS-AcquiringMonitor-0.2.11-setup.exe` — рекомендуемый установщик с автообновлением.
- `KRS-AcquiringMonitor-0.2.11-win-x86.zip` — portable-сборка, обновляется вручную.
- `update.json` — версия и SHA-256 установщика для встроенного обновления.

Требуются Windows 10/11 и .NET Framework 4.8. Все компоненты — x86. Банковские DLL и журналы в комплект не входят.
